# 2.0.0rc1 product continuation

- New native desktop frontend: Home, Explore, Analyze, Evidence, Calibrate,
  Settings and Help, with docks and centralized calm scientific theme.
- Separate four-gesture intent layer, deliberate relative pinch calibration,
  release/rearm, exclusive owners and discontinuity/unknown/loss cancellation.
- Shared WORLD/HAND scenes and timestamp-smoothed palm anchoring; separate
  two-hand provider, conservative association, clutch scale and pair measurement.
- Nine educational labs and point-based construction/measurement tools.
- Mouse/keyboard fallback, session logs, persisted preferences, explicit camera
  errors, bounded presentation mailbox and stop/restart resource ownership.
- Setup/launch, reproducible source packaging, synthetic native render QA and
  product safety/math/UI/provider tests.
- Follow-up hardening: modal interruption/rearm, native editing shortcuts,
  exclusive mouse takeover, distinct manual/gesture commit IDs, shared two-hand
  pointer mapping and continuous window-to-scene cursor/picking coordinates.
- Camera startup fix: use the frozen factory's controller presentation hook;
  retain startup failure details after cleanup and log diagnostic tracebacks.
  The real V2 Start/Stop camera path has now passed a bounded physical no-hand
  run. This does not validate real-hand gesture usability.

Frozen Core, G7 experiments/evidence and both original release tags are preserved.
The new product stream does not constitute additional research evidence.

Known limitations: physical calibration/handedness/usability unverified; projected
hand association is not identity tracking; large crossings cancel; view-parallel
construction planes can be unavailable; scenes use scene units and educational
models; GPU availability varies; source archive needs installed dependencies.
