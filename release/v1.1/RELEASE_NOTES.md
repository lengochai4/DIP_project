# v1.1 application candidate — physical acceptance pending

- New default SIMPLE controls: one index finger rotates, one open palm opens
  Control Space and selects by hover dwell, two open palms scale. No PINCH release
  reference/calibration is required. A stationary palm cannot select on menu entry;
  move first, then dwell. Selection is latched until leaving the target.
- Practical OPEN uses known extended non-thumb fingers and allows a comfortable
  thumb. A3/FIST classification, legacy semantics and research parameters are unchanged.
- SIMPLE gets two-hand capability at launch, mirrored preview, live action state,
  selection progress, Help and four fitting input-mode choices in Settings.

The legacy-default wording below describes the earlier PINCH-first candidate,
superseded by the explicit practical-controls product decision on 2026-10-02.

- Explicit release enrollment and immutable relative-intent reference, independent
  temporal closing/hold/release/rearm with safe UNKNOWN/loss/reacquisition/reset.
- Legacy-default and OBSERVE parity path; experimental one-hand POINT rotation,
  PINCH scale/selection, OPEN release and diagnostic-only FIST. Exclusive command owner.
- Application Settings, session calibration, saved ergonomic preferences, three
  sensitivity presets, consistent mirrored preview/new input mapping, full-hand
  feedback, onboarding/help, keyboard and right-drag/wheel fallback.
- Separately opt-in two-hand provider/association and OPEN-pair projected scale;
  ambiguous/lost pairs neutralize. Frozen single-hand Core is unchanged.
- Unique run identity, local journals, modal focus safety, lifecycle fault tests,
  source snapshot tooling, launcher and labeled synthetic screenshots.
- CPU UI profiling identified broadcast background fill; a bounded immutable
  template with independently owned output copies reduces that measured work.
  No end-to-end webcam performance claim is made.

Known limitations: physical v1.1 usability gate remains pending; FIST reliability
is not repaired or validated; projected palm compatibility can require calibration
after angle/source changes; two-hand association is geometric, not biometric;
occlusion/dark light can lose tracking; independent two-hand inference costs extra;
release reference is session-only; sensitivity does not alter legacy output; the
source package requires Python/OpenGL/dependencies and a separately supplied model.
No standalone installer, commercial validation or broad device/user robustness is claimed.

G7/Core/report/evidence/final experiments and immutable `g7-final` /
`dip-touchless-stem-v1.0` remain unchanged. G9 remains stashed and absent.
Do not publish/tag this candidate before practical physical acceptance and review.
